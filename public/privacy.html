Resonate ホームへ

プライバシーポリシー

最終更新日：2026年11月8日

Resonate（以下「本アプリ」）は、好きなエンタメコンテンツをさりげなく友人・知人と共有し、関係を深めることを目的としたWebアプリです。本ポリシーでは、本アプリが取得・利用する情報について説明します。

取得する情報

  • Firebase Authentication（匿名認証）により発行される、個人を特定しない匿名のユーザーID
  • 共有コンテンツに関する情報（ジャンル・タイトル・好きなポイント・生成されたメッセージ・任意で入力した送信者名や相手のメモ）
  • 受け取った相手によるリアクション（絵文字・任意のコメント）
  • 任意でアップロードされたLINEトーク画面のスクリーンショット（メッセージのトーン分析にのみ使用し、保存はしません）

YouTubeの情報へのアクセスについて

本アプリの「YouTube連携」機能を利用する場合、Googleアカウントの認可（OAuth）を通じて、ユーザー自身の「いいねした動画」または「登録チャンネル」の一覧（タイトル・サムネイル画像・リンク）を取得します。

取得した情報は、以下の目的にのみ使用します。

  • 共有相手に合いそうなコンテンツ候補をAI（Gemini）が選び、提案画面に表示するため

取得したYouTube関連データは、提案を表示する処理の中でのみ一時的に使用され、サーバー側のデータベースに永続的に保存することはありません。広告目的での利用、第三者への販売・提供、本アプリの提案機能以外の目的での利用は一切行いません（Google API Services User Data Policyの制限付き使用要件を遵守します）。

情報の第三者提供・外部サービスの利用

本アプリは、以下の外部サービス（いずれもGoogle社が提供するもの）を利用して情報を処理します。

  • Firebase（Authentication / Firestore / Hosting / Cloud Functions）
  • Vertex AI（Gemini API） — メッセージ生成・提案生成のため
  • Google Custom Search API — 共有カードの画像取得のため
  • YouTube Data API — 上記「YouTubeの情報へのアクセスについて」の目的のため

これら以外の第三者に対して、取得した情報を販売・共有することはありません。

データの保存期間・削除

共有コンテンツ・リアクション等のデータは、送信者本人がマイページから削除できる範囲で保存されます。削除をご希望の場合は、下記連絡先までご連絡ください。
